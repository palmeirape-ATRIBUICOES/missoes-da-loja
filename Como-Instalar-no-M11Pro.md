# 📱 Guia de Instalação "Casca de Ovo" (WebView APK) para o M11Pro

Este guia orienta você a criar e instalar a **"casca de ovo" (WebView Wrapper)** no seu terminal portátil **M11Pro**. O aplicativo nativo funcionará em tela cheia sem nenhuma barra de navegação, carregando tudo diretamente do servidor do GitHub.

Qualquer atualização no sistema será refletida **automaticamente** no aparelho sem a necessidade de gerar um novo APK!

---

## 🚀 Como gerar o seu APK em 1 Minuto (Grátis)

Como o computador de desenvolvimento não possui o Java JDK configurado, a maneira mais rápida, profissional e gratuita de obter o seu APK assinado é utilizando a plataforma **WebIntoApp**:

1. Acesse o site: **[https://www.webintoapp.com/](https://www.webintoapp.com/)**
2. Clique em **"Get Started"** (Começar).
3. Preencha as configurações do aplicativo:
   * **URL do Aplicativo:** `https://palmeirape-atribuicoes.github.io/missoes-da-loja/`
   * **Nome do Aplicativo:** `Missões da Loja`
   * **Tipo:** `Google Chrome / WebView`
4. Na aba de **Ícone (App Icon)**:
   * Faça o upload do arquivo de ícone localizado no seu projeto em:
     `c:\Users\thiag\OneDrive\Área de Trabalho\missoes-da-loja-main\missoes-v2\public\apple-touch-icon.png` (ou `icon-512.png`).
5. Nas configurações avançadas (Display & Orientation):
   * Defina **Orientation** como `Portrait` (Vertical).
   * Defina **Display** como `Fullscreen` ou `No Title Bar` para remover qualquer borda de navegador.
6. Clique em **"Generate APK"**.
7. Baixe o arquivo `.apk` final direto para o seu computador ou escaneie o QR Code gerado para baixar direto no M11Pro!

---

## 📲 Como instalar o APK no M11Pro

1. **Enviar para o Aparelho:**
   * Envie o arquivo `.apk` gerado para o M11Pro via cabo USB, WhatsApp Web, Google Drive, ou escaneando o QR Code de download diretamente com a câmera do M11Pro.
2. **Habilitar Fontes Desconhecidas:**
   * Caso o Android do M11Pro bloqueie a instalação, vá em **Configurações > Segurança > Instalar apps desconhecidos** e dê permissão para o navegador ou gerenciador de arquivos.
3. **Instalar e Rodar:**
   * Abra o arquivo `.apk` no M11Pro e clique em **Instalar**.
   * Pronto! O aplicativo aparecerá na tela inicial como um app nativo, abrindo diretamente em tela cheia e conectando-se ao seu servidor.
